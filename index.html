でらぼ

人文知を愛するWebエンジニア。
評論家ではなく実装者として、テクノロジーを世界に対して適切に使う道を考えています。

哲学科の大学院修了後、予備校に約5年間勤務し、31歳でWebエンジニアに転職。現在は渋谷の受託開発企業で、Webアプリケーションのサーバーサイドを中心に開発しています。

大学院時代は哲学の研究職を志していましたが、道半ばでアカデミアからは離れ、予備校に就職。30代を迎えて改めて「世界にとって本当に意味のあることをしたい」という思いに向き合い、エンジニアへ転身しました。

現在は開発現場で経験を積みながら、社外にも活動の場を広げています。

培ってきたもの

問いを立てる哲学

大学院まで哲学を専攻し、現状を疑い、俯瞰的に問い直す訓練を続けてきました。社会課題と技術の観点を結びつけて考えられる思考回路は、この訓練によるところが大きいです。

人と組織の間マネジメント

予備校で教室長・エリア責任者を約3年。エンジニア転職後も5名体制の開発リーダー（PM兼開発）としてスケジュール管理やメンバー指導を担い、現職では組織マネージャーも経験しました。技術だけでなく、人が動く時も目にしてきました。

形にする実装

Ruby on Rails と Laravel などのバックエンド開発を主軸に、新規開発から保守運用まで。約40名のスクラム体制でのAPI設計・実装や、総ユーザー数15万人規模の新規開発にコアメンバーとして参画してきました。

AIとの関わり

生成AIは、業務でも個人開発でも日常的に使う道具になっています。部署内でのClaude導入も推進しました。社内ハッカソンで発表したSmall Voiceも、生成AIを使って小さな声を集め、可視化するWebサービスです。

一方で、AIの進歩の陰には、暴走のリスク、搾取の構造、環境への負荷、合理化された人間理解といった問題も潜んでいます。その恩恵を受けている当事者として、そこから目をそらさずに、適切な関わり方を模索したいと思っています。

関心

  • デジタル・リアル双方での対話空間の創出

    学生時代から「哲学」は私の考え方のベースにあり、それを手放さず、休日は有志の哲学対話に積極的に参加しています。ホッとできて、ゆっくりと自分の話したいことを話せ、他人を否定しない、他人を制圧しない言葉で交わされる言語空間のニーズがどれだけ高まっているか、参加するたびにひしひしと感じています。デジタルの側ではブロードリスニングやプルラリティに関心があり、Small Voice もその一環として自身で形にしてみたものです。

  • Code for Japanなどのシビックテック領域

    イベントやサミットにも、積極的に参加し始めています。まずは自分事として、熱い体温を持って取り組める社会課題を見つけ、ボランティアからでも開発のできるエンジニアとして関わっていきたいと思っています。

  • 人文知とテクノロジーの融合

    いまも哲学書や純文学、批評などを、時間を見つけて読むようにしています（嗜好）。ドイツ語翻訳もその一環として続けています（全然読めませんが）。自分の根底にある世界観を見失わず、自分へ戻ってくるための習慣のようなものと位置付けています。社内LTで話した「文学や詩をプログラミング的に考えてみる」も、その往復があってこその発想でした。
